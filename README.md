# Studio Roses · Cuestionarios de la fase 1

Páginas estáticas de Taltalab para que Rafa y Cori respondan por voz o por escrito.
- `rafa.html` y `cori.html`: 22 preguntas en 6 bloques, una por pantalla. El dictado usa el reconocimiento de voz del navegador (Chrome, Safari, Edge).
- Las respuestas se guardan solo en el navegador de quien responde y se envían por WhatsApp o correo desde la última pantalla. No hay servidor ni base de datos.
